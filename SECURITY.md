# Security

Report vulnerabilities privately through this repository's GitHub **Report a
vulnerability** control when enabled. If that control is unavailable, contact
the repository owner privately through an established channel; do not post
malicious inputs or exploit details in a public issue.

No release is supported yet. Release qualification must include the exact
native source pin, linked codec inventory, malformed-input corpus, callback
lifetime tests, fuzz results and approved native build identities. A crash or
hang blocks release. A verified checksum proves artifact identity, not parser
safety. See the README threat model before using untrusted data.
